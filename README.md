# Бот-калькулятор для сравнения цен на металлопрокат

Бот для отдела снабжения. Сравнивает предложения от разных поставщиков металлопроката, пересчитывая всё через физический вес металла (по формулам ГОСТ / [металлического калькулятора](https://metallicheckiy-portal.ru/calculator/calculator_metalla)).

Снабженец может скинуть:
- **Текстовые сообщения** (например: `труба 40х40х2 6 метров - цена 567,64 грн`, `труба 40х40х2 цена 45000/т`, `лист 2мм 1.25х2.5 25000/т`, `арматура 12 12м 320 грн`). Можно отправлять списком из нескольких строк сразу или пересылать сообщения поставщиков.
- **Фото или PDF накладных** (например, счета от «Метал Холдинг» с ценами за тонну и спецификацией).

После нажатия кнопки **«🔍 Начать анализ»** бот:
1. Автоматически приводит каждую позицию к цене за **1 кг** и **1 погонный метр** (или м² для листа).
2. Находит и сопоставляет одинаковые позиции между поставщиками.
3. Показывает, у кого закупаться дешевле и на сколько процентов (🏆 *ЛУЧШАЯ ЦЕНА* / *+X% дороже*).
4. Формирует и отправляет красивый **Excel-файл** со сводной таблицей и подсветкой лучшей цены.

## Что нужно получить (всё бесплатно, без привязки банковской карты)

1. **Токен бота** — напиши в Telegram **@BotFather** → `/newbot` → следуй подсказкам → получишь строку вида `123456:ABC-DEF...`.
2. **OCR-ключ** (для распознавания фото и PDF накладных) — зайди на https://ocr.space/ocrapi, введи email, получишь бесплатный ключ на почту (500 страниц в день).
3. **Upstash Redis** (хранилище буфера предложений) — зарегистрируйся на https://upstash.com (можно через аккаунт GitHub), создай базу Redis (Free tier — 10 000 команд в день), в разделе *REST API* скопируй `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
4. **Vercel-аккаунт** — https://vercel.com, вход через GitHub (бесплатно).

---

## Деплой на Vercel

1. Залей проект в репозиторий на GitHub.
2. На vercel.com нажми **"Add New Project"** → выбери созданный репозиторий → нажми **Deploy**.
3. В настройках проекта (Settings → Environment Variables) добавь 4 переменные из файла `.env.example`:
   - `TELEGRAM_BOT_TOKEN`
   - `OCR_SPACE_API_KEY`
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
   После добавления переменных нажми **Redeploy**.
4. Открой в браузере `https://<твой-проект>.vercel.app/api/set-webhook` один раз — это подключит бота к Telegram. Должен вернуться ответ: `{"ok":true,"webhook":"..."}`.
5. Открой бота в Telegram, нажми `/start` — готово!

---

## Как пользоваться

- **Текстом:** `труба 40х40х2 6м 567,64 грн` или `труба 40х40х2 цена 45000/т` или `лист 2мм 25000/т`.
  Если сообщение переслано из чата поставщика, бот сам возьмет его имя!
- **Файлом:** пришли фото или PDF счет-накладную (бот сам найдет поставщика в шапке документа и вытащит все позиции со спецификацией).
- `/status` — посмотреть текущий список позиций в буфере.
- `🔍 Начать анализ` — сравнить предложения и получить Excel-отчёт.
- `🗑 Сбросить` (или команда `/reset`) — очистить буфер.
